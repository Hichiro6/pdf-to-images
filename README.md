# PDF to Images

> Extract PDF pages as images in your browser. Choose order, format, and quality. 100% local, your files never leave your browser.

## Features

- **Privacy-first** — No backend, no uploads, no tracking. Everything happens in your browser.
- **No installation** — Works directly in the browser.
- **Accessible** — ARIA-compliant, keyboard navigation, screen reader support.

## Tech Stack

- pdfjs-dist
- fflate
- [Vite](https://vitejs.dev/)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm run test:run
```
